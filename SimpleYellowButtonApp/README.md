# SimpleYellowButtonApp

Простое Windows Forms приложение на C# с одной жёлтой кнопкой и картинкой с элементами управления.

Что добавлено:
- PictureBox, показывающий изображение с элементами управления.
- Панель с кнопками Play/Pause, Stop, TrackBar (симуляция прогресса) и меткой процента.
- Таймер, имитирующий прогресс воспроизведения.

Требования:
- .NET 8 (или измените TargetFramework на net7.0-windows / net6.0-windows)
- Windows (WinForms)

Установка изображения:
1. Создайте папку `assets` в корне проекта.
2. Поместите вашу картинку с элементами управления в `assets/controls.png`.
   - Можно использовать любое имя, но тогда измените путь в `MainForm.Designer.cs` (`pictureBoxControls.ImageLocation`).

Сборка и запуск:
1. Откройте терминал в папке проекта.
2. dotnet build
3. dotnet run

Или откройте проект в Visual Studio и запустите (F5).

Примечания:
- Панель с контролами сделана простым FlowLayoutPanel'ом поверх изображения.
- Если хотите, чтобы контролы были прорисованы поверх самой картинки (overlay) с прозрачностью, можно использовать кастомную отрисовку или WPF для более гибкой прозрачности/слоёв.
